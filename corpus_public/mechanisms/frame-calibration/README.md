# Public frame calibration

These public fixtures test the declared eager-only frame profile. They do
not measure reconstruction quality. The archived v1 fixture stays unchanged.

`recursive.c` calls a recursive function through a volatile function pointer.
The function uses four distinct integer arguments. It uses the child result
after each call. The live gate must verify a caller stack frame in each
required build. A separate empty function and call sequence support entry,
return, and shared-role calibration.
The compiler output must establish which shared roles actually occur.
Source shape alone does not establish a machine instruction pattern.

`callback.c` calls `qsort` with a comparator in the original image.
The first profile must reject that callback during the opaque external
interval. Run one scope with the comparator selected and another with it
omitted. Neither scope may admit a tree or export local register facts.
The full process outcome must still match both accepted oracle engines.

The manifest fixes all source and case hashes before Linux execution.
Both compilers build both fixtures at O0 and O2. These new fixtures declare
immediate binding from their creation. They do not change an archived
Invocation or add an observation-only loader setting. Retain the original
Clang lazy-resolution rejection controls separately.

`-fno-optimize-sibling-calls` preserves call and return calibration in this
fixture profile. It is a declared calibration flag. It is not a benchmark
input flag or a change to the sealed compiler matrix.

Host syntax checks are permitted. Compile and execute targets only in the
Linux containers after the private author releases the VM. The live gate
must record exact binary hashes, symbol truth, stripped inputs, full plans,
scopes, runtime pins, raw wire, receipts, outcomes, and every rejected case.
Three repetitions and actual collector mutation controls remain required.
