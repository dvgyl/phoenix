# Check observation mapping before frame admission

A complete wire record proves record structure only. A mapped observation
must also match the exact binary, reconstructed static plan, invocation,
and runtime digest. Rebuild the canonical plan at this boundary. Reject a
changed plan or proof before interpreting runtime events.

Require equality of the complete supplied observer outcome and the
accepted development outcome. This includes output bytes, termination,
and the final filesystem. A mismatch rejects observation evidence only.
It cannot change the expected outcome or evaluation denominator.

Map the runtime code envelope to the original executable file ranges.
Use one nonnegative bias. A fixed-entry executable needs zero bias.
Reject targets in data, ambiguous segment owners, and executable holes.
Retain external runtime targets as opaque values.

Check event roles against the plan. A direct call must confirm its exact
byte-derived destination. A return confirmation must equal its recorded
stack target. A continuation must refer to the correct admitted call
and its exact plan continuation. Empty or incomplete capture rejects.

An internal target identifies an address in executable file bytes.
It does not establish an instruction start, function identity, target
closure, or a valid activation frame. The returned MappedObservation
does not authorize recovery.

The live launcher must bind the raw trace and observed outcome from one
capture. Its runtime proof must establish actual component identities
and calibrated capabilities. This unit checks the supplied runtime
digest only. Frame admission, root scope, stack discipline, import
transit, nonreturn contracts, and live support remain separate gates.
