# Preserve checked switch source during cleanup

The checked switch emitter consumes the original binary, parsed lift,
address proof, normalized graph, and ordinary source observations.
The bounded C parser checks the complete function. Marker binding
checks every ordered role, value, and exact UTF-8 byte span.

The emitter then checks the selector storage and mask, all selector
labels, the default, owned arm blocks, the unique indirect predecessor,
and the shared continuation. Stacked labels must name one target.
Each target has one source group. Unsupported relations deny emission.

Replace only the validated selector expression and numeric label spans.
Reparse the result. Keep each arm, break statement, and continuation
byte for byte. This preserves ordinary C structure. It does not prove
that every ordinary arithmetic or memory operation matches the binary.

A protected definition keeps that source during cleanup and repair.
Its fixed prefix supplies the exact unsigned 32-bit alias and typed
data initializers. Admit only supported data names, matching widths,
one writable non-executable data owner, and no relocation overlap.
An unsupported initializer or dependency denies protection.

Write protected definitions before model declarations in the same
translation unit. Model declarations cannot change earlier preprocessing.
The candidate parser accepts model definitions only for ordinary
functions. It retains protected values separately. Rename only the
parsed function definition token to the existing Phoenix name.
Do not change the body through indentation or text cleanup.

The source admission result distinguishes supported C, an unsupported
syntax or capacity gap, and conflicting marker correspondence. The
lower artifact reader still rejects invalid identity and records.
An unsupported function does not remove another admitted function.

This block adds pure binding, emission, and writer APIs. The runtime
pipeline caller and Linux behavior checks remain separate work.
Ghidra-raw keeps its ordinary source path. No new milestone claim
follows from syntax checks or source identity.
