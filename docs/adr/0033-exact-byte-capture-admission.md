boundary that constructs that record from exact saved bytes. Reparse the
lift and mapping. Rebuild the address proof, full plan, and requested scope.

The raw artifact record contains wire, receipt, runtime manifest, and observed
outcome bytes. Parse these with strict fields, types, and limits. Compare
the runtime manifest with an independent runner pin. Bind the wire identity,
receipt, accepted invocation, and complete observed outcome before reduction.
A raw-boundary failure exports no local register observations.

Classify root predecessor and saved return target with the checked image.
Require both outside the complete original load-segment envelope. Apply
the same range restriction to every opaque transfer. This excludes gaps
between load segments. It is a conservative capture rule. The reviewed
lower mapper contract remains unchanged.

runtime, scope, guard, and policy identities. Its declared QEMU 9.2.0 pin
comes from the existing observer experiment. The future pinned runner
must establish actual runtime use and association with one execution.

controls do not close actual collector calibration or mutation gates.
