# Use checked switch definitions in reconstruction

Add `--checked-switches` as an explicit Phoenix option. Keep it off
until the public Linux behavior gate passes. Save its value in the run
record. Resume and replay must retain that value. Ghidra-raw rejects it.

When enabled, publish lift, address mapping, normalized switch graph,
and ordinary source observations as one schema 3 generation. Resume
through the checked generation selector. Recover the Program from the
same validated lift bytes. Reject malformed companion identity before
function admission.

The switch plan validates supported functions and retains per-function
gaps and marker conflicts. A missing graph, unsupported source, unproved
machine relation, or unproved data dependency cannot produce a protected
definition. Invalid whole-artifact evidence still fails the stage.
Record the rule version and source, graph, proof, and data identities.

Pass the retained definitions through initial cleanup and every repair.
Only ordinary definitions enter the model response. The writer emits
protected source before model declarations. The final package contains
the tested source snapshot and its checked-switch record. A protected
function does not become behaviorally verified through this record.

Keep the ordinary reconstruction and Ghidra-raw paths available.
The host controls establish source preservation and replay behavior.
Actual four-way Linux builds, full differential outcomes, and the
unvisited-case control remain required before enabling the option
in a sealed measurement.
