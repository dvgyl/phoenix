# Timed pause records

These records preserve public work for the requested pause. The design
documents are exact copies. The manifest binds their original paths,
lengths and SHA-256 values. Links inside each original report can refer
to files in its original local audit directory. Those directories remain
on the external workspace. No private source, input or Author log is
included. No archived document supplies production authority.

The final pause record in `docs/HANDOFF.md` states the observed shutdown
and resume conditions. A draft review does not certify that later state.
